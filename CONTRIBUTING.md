# Contributing

Contributions may improve a research question, method, source evaluation, template, or public research note.

Read the [research method](docs/research-method.md) and [publication standards](docs/publication-standards.md).

## Requirements

- Explain the research question or methodological problem.
- Use legitimate public sources and attribute them.
- Record source locations supporting material claims.
- Separate observation, interpretation, and hypothesis.
- State review status and limitations.
- Keep unpublished or confidential material out.
- Do not invent results, citations, affiliations, or author contributions.
- Keep detailed security specifications and threat scenarios in their dedicated repositories.

Use the [research-note template](templates/research-note.md) for a new note. A pull request should explain the change, supporting evidence, and any effect on existing conclusions.
